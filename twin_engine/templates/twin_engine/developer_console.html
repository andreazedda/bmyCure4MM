How to use this console

Question answered
Are the data, model, causal assumptions, scientific registry, artifacts, privacy controls, and developer outputs coherent enough for research review?
Inputs used
Database records, model outputs, model_references.json, artifact metadata, staged git paths, and local feedback.
Method / computation
Offline checks return pass/warn/fail with object ids, details, and a suggested fix.
Output meaning
Pass means no issue detected, warn means review required, fail means do not share or push until resolved.
What you can do next
Use each next action, rerun this console, then run the pre-push safety check.
Limitations
A passing console is an audit signal, not proof of external validity.
