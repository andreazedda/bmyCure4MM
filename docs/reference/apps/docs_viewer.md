# App `docs_viewer`

## Scopo

Viewer interno di documentazione Markdown con:

- rendering
- ricerca
- analytics (view)
- feedback (rating/commenti)

## Modelli

`docs_viewer/models.py`:

- `DocumentView`
- `DocumentFeedback`

## Comandi management

- `docs_viewer/management/commands/validate_docs.py`: validazione di base della documentazione disponibile.
